# ตำบลฮอนกฮูก: ชุดฝึกวางแผนรับมือภัยพิบัติ

ชุดสื่ออบรมแกนนำชุมชนและสภาองค์กรชุมชน ใช้ฝึกวิเคราะห์ห่วงโซ่ผลกระทบ (impact chain) และผลต่อสุขภาพ (health outcome) จากน้ำท่วม น้ำป่าไหลหลาก และดินถล่ม
ภูมิประเทศเป็นของจริง คือเทือกเขาหลวงด้านตะวันออก จ.นครศรีธรรมราช ใช้ข้อมูลความสูง SRTM จาก AWS Terrain Tiles ส่วนชุมชน ผู้คน และเหตุการณ์ทั้งหมดเป็นเรื่องสมมติ

แผนที่ 3 มิติออนไลน์: https://honnokhuk.pages.dev/ (deploy จากโฟลเดอร์ `site/` ด้วย GitHub Action `.github/workflows/deploy-honnokhuk.yml`)

## สิ่งที่ได้ (`output/`, `web/`, `site/`)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `output/map-1-base-A1.pdf` | แผนที่ฐาน A1 มาตราส่วน 1:10,000 ไม่มีชั้นความเสี่ยง ให้กลุ่มระบายสีเอง (ใบงานที่ 1) |
| `output/map-2-risk-A1.pdf` | แผนที่ความเสี่ยงฉบับวิทยากร แสดงน้ำท่วม 3 ระดับ น้ำป่า น้ำขัง ดินถล่ม กลุ่มเปราะบาง และเส้นทางอพยพ |
| `output/workbook.pdf` | คู่มือผู้เข้าอบรม A4 มีข้อมูลตำบล เรื่องเล่า 8 ช่วง ใบงาน 1–5 และทะเบียนครัวเรือน 120 หลัง |
| `output/facilitator.pdf` | คู่มือวิทยากร มีกำหนดการ 1 วัน ประเด็นชวนคุยแต่ละช่วง และเฉลย impact chain กับตารางผลต่อสุขภาพ |
| `web/honnokhuk-3d.html` | แผนที่ 3 มิติสำหรับโทรศัพท์ เปิดในเบราว์เซอร์ได้เลย หรือนำไปวางบนเว็บโฮสต์ใดก็ได้ (โหลด three.js จาก CDN) |

## สร้างใหม่

```bash
pip install numpy scipy matplotlib pillow qrcode
python3 scripts/analyze.py data/dem_mosaic_z13.npy data   # วิเคราะห์ภูมิประเทศ: ทางน้ำ แอ่ง HAND ความชัน ดินถล่ม
python3 scripts/build_village.py                          # วางผังชุมชนและคำนวณความเสี่ยงของแต่ละหลัง
python3 scripts/render_base.py                            # สร้างภาพพื้นแผนที่
python3 scripts/export_web.py                             # สร้างแผนที่ 3 มิติ
python3 scripts/make_maps.py https://honnokhuk.pages.dev/ fonts       # สร้างแผนที่กระดาษพร้อม QR
python3 scripts/make_docs.py https://honnokhuk.pages.dev/             # สร้างคู่มือ PDF (ต้องมี Playwright)
```

แก้เรื่องเล่าได้ที่ `data/story.json` ข้อความในไฟล์นี้ใช้ทั้งในแผนที่ 3 มิติและในคู่มือ

## วิธีคำนวณ (แบบง่าย เพื่อการเรียนรู้)
- น้ำท่วมใช้ความสูงเหนือทางน้ำที่ใกล้ที่สุด (HAND) แบ่งเป็น 3 ระดับ: ไม่เกิน 1.5 ม. คือท่วมทุกปี, ไม่เกิน 3 ม. คือปีน้ำมาก, ไม่เกิน 5 ม. คือปีวิกฤต
- น้ำป่าไหลหลากคือทางน้ำที่มีพื้นที่รับน้ำมากกว่า 3 ตร.กม. และอยู่ต่ำกว่า 3 ม. จากทางน้ำ ส่วนน้ำขังคือแอ่งที่ได้จากการเติมแอ่งบนผิวภูมิประเทศ (priority-flood)
- ดินถล่มคิดจากความชัน (เกิน 15–35°) ร่วมกับร่องรับน้ำบนลาด
- ทั้งหมดนี้ไม่ใช่แบบจำลองทางวิศวกรรม และใช้พยากรณ์ภัยจริงไม่ได้
